# Oxide

**An open-source operating system built from scratch in Rust.**

> **Oxide is in very early development.** Everything is experimental and subject to change.

## About

Oxide is a general-purpose operating system project built from the ground up with Rust.

The goal is to create a modern, open-source operating system with its own kernel, userspace, and eventually a complete desktop environment and ecosystem.

Oxide is designed to be developed openly, with the long-term goal of allowing anyone to contribute, modify, and build their own distributions based on the Oxide platform.

## Goals

* Rust-first kernel
* Open-source development
* General-purpose computing
* Modern hardware support
* Strong focus on safety and reliability
* Community-driven development
* A flexible foundation for future Oxide-based distributions

## Current Status

**Very early development.**

Right now, the project is primarily focused on building the kernel and establishing the foundations of the operating system.
